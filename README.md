## 🛠️ Tech Stack & Architecture

- **Frontend**: HTML5, Tailwind CSS, Lucide Icons, Canvas Confetti, Leaflet.js
- **Map & Transit Engine**: Leaflet with Google Maps Roads tile layer (`https://mt{s}.google.com/vt/lyrs=m...`) & real Bhopal road polylines
- **Backend & APIs**: Python 3 HTTP Server (`server.py`) serving:
  - `/api/routes` — All 43 SISTec routes
  - `/api/bus` — Fleet telematics & live vehicle data
  - `/api/route-geometry/<id>` — High-resolution Bhopal road coordinates
  - `/api/bus/stream` — Real-time Server-Sent Events (SSE)
- **Database**: SQLite3 (`attendance_bot.db`)
- **Telegram Framework**: `python-telegram-bot v20+`

## 💻 Local Setup & Execution

### 1. Clone & Enter Repository
```bash
git clone https://github.com/priyanxsk/SagarTracker.git
cd SagarTracker
```

### 2. Install Python Dependencies
```bash
pip install -r requirements.txt # or: pip install python-telegram-bot python-dotenv playwright
```

### 3. Run Web Server
```bash
python3 server.py
```
Open **[http://localhost:8080](http://localhost:8080)** in your browser.

### 4. Run Telegram Bot
```bash
python3 run_bot.py
```
Send `/start` to **[@Butlerrxsbot](https://t.me/Butlerrxsbot)** on Telegram.
